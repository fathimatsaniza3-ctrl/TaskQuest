# TaskQuest — Productivity? Absolutely Not.

A humorous, deliberately over-engineered mini-game task unlocker for a useless-software hackathon.

## Funny features
- Three new arcade mini-games gate a focus session: Emoji Emergency Decoder, Panic Reflex Test, and Brain-Rot Memory Vault. Each task requires all three games in a randomized order.
- Ridiculous excuse generator (cosmic, technical, academic, dramatic).
- HOD email parody generator. It only drafts/copies text; it never sends email.
- Delay Wheel randomly invents pointless obstacles.
- Local stats for quests, game wins, and focus minutes.

## Run
Extract the ZIP and open `index.html` in a browser. No installation, backend, internet, or API keys required.\n
## Demo
1. Enter a task and begin the pointless procedure.
2. Win a mini-game to unlock focus mode.
3. Generate an absurd excuse or mock HOD email.
4. Spin the Delay Wheel and show the statistics.

## Updated mini-games
- **Emoji Emergency Decoder:** decode funny emoji situations; get at least 2 of 3 correct.
- **Panic Reflex Test:** wait for green, then click quickly without a false start.
- **Brain-Rot Memory Vault:** memorize and repeat a four-symbol sequence.

The mini-games run locally in your browser. No accounts, APIs, or internet are required for the games.
